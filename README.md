# IRIX PACK — списки сборки маркетплейсов в разноску по остаткам

Связка из двух частей, которая закрывает путь от документа сборки до цифры в таблице остатков:

1. **IRIX PACK** — HTML-приложение. Читает PDF из кабинета (список сборки Ozon, лист подбора Wildberries), собирает количества по артикулам и выгружает акт в формате для загрузки.
2. **Отгрузки** — скрипт Google Apps Script для таблицы остатков. Принимает акт, сопоставляет артикулы со строками таблицы, пересчитывает коробки в штуки и пишет их в столбец нужной даты и площадки.

Части работают и по отдельности: из приложения можно забрать столбец количеств и вставить руками, а скрипт принимает любой акт подходящего формата, не только сделанный приложением.

| Файл | Что это |

## Часть 1. Приложение IRIX PACK

### Что делает

- Разбирает два формата PDF:
  - **Ozon, список сборки** — колонки «№ Фото Товар Артикул Кол-во», количество берётся из строки;
  - **Wildberries, лист подбора** — колонки «№ задания Фото Бренд Наименование Размер Цвет Артикул продавца Стикер», одна строка равна одному заданию, задания складываются по артикулу.
- Определяет размер комплекта: сначала по суффиксу артикула (`4шт`), затем по названию товара (`2 шт`), иначе товар считается штучным. Размер можно исправить вручную в сводке — всё пересчитается.
- Сверяет итог с шапкой документа («Количество отправлений», «Количество товаров») и подсвечивает расхождение.
- Отсекает повторно загруженные документы.

### Как пользоваться

1. Открыть `IRIX_PACK_spiski_sborki.html` в браузере.
2. Положить PDF в зону своей площадки — **Ozon** или **Wildberries**. Площадку задаёт зона, а не текст внутри файла: если внутри указана другая, приложение предупредит, но послушается зоны.
3. Проверить карточки: склад или номер листа, дата, позиции, штуки, сходимость с шапкой.
4. Забрать результат одним из способов ниже.

### Форматы выгрузки

**Акты для разноски** — по одному файлу на каждую дату и площадку, `Акт_31-08-2026_оз.xlsx`:

```
Дата:                    31.08.2026
Количество отправлений: 23
Служба доставки: Ozon

Артикул            Кол-во
форио шок/беж           3
форио шок/беж 4шт       1
```

Количество здесь — **коробки**. Штуки считает скрипт разноски из наименования в таблице остатков, поэтому отдавать ему штуки нельзя: получится двойное умножение.

**Столбец под таблицу остатков.** В поле внизу вставляется столбец «Артикул продавца» из листа остатков, приложение возвращает количества **в штуках** строго в том же порядке строк, с пустыми там, где отгрузок не было. Кнопка «Копировать столбцы» кладёт результат в буфер, вставляется в колонку нужной даты. Артикулы сопоставляются без учёта регистра, пробелов, дефисов и слэшей: `форио шок/беж-4шт` находит `форио шок/беж 4шт`.

**Excel** — четыре листа: «Для разноски» (артикул и штуки по датам), «Столбец в порядке строк» (если столбец построен), «Сводка по артикулам», «Список сборки» с детализацией по складам.

### Ограничения

- Нужен PDF с текстовым слоем. Фотографии и сканы не читаются: в кабинете лист печатается через «Сохранить как PDF», а не снимается на телефон.
- Артикул, разорванный переносом, склеивается по правилу формата: в листе подбора без пробела (`СПКЛАЗ-гол11венге/с` + `ершен`), в списке сборки через пробел (`форио свдуб/беж` + `4шт`).
- Приложение не знает, что лежит в вашей таблице остатков, пока туда не вставлен столбец артикулов.

## Часть 2. Скрипт разноски

### Установка

1. Расширения → Apps Script.
2. Содержимое `Отгрузки.gs` — в файл скрипта. Файл должен быть **один**: если рядом останется старая версия, два объявления `CFG` конфликтуют и работает случайная.
3. Файл → + → HTML, имя ровно `Загрузка`, туда `Загрузка.html`.
4. Сервисы → + → **Drive API v2** — нужно для чтения xlsx.
5. Сохранить, перезагрузить таблицу. Появится меню «Отгрузки».

Проверка: меню «Отгрузки» → «Проверка кода». Покажет версию, лист «Отгрузка» и объединённые ячейки на рабочем листе. Внизу панели загрузки та же версия — если её нет, выполняется старый код.

### Работа

1. Меню «Отгрузки» → «Загрузить акт».
2. Выбрать лист месяца и площадку, приложить файл акта, нажать «Проверить».
3. На листе «Отгрузка» появится распознанное, в панели — дата, столбец, коробки, штуки, несопоставленные артикулы и предупреждение о возможном дубле.
4. «Разнести» — числа уходят в столбец даты и площадки, лист «Отгрузка» очищается, в «Лог разноса» пишется строка.

Если столбца на эту дату и площадку нет, скрипт создаёт пару столбцов «дата + вб» и «дата + оз» после последней даты.

### Устройство таблицы остатков

Скрипт рассчитывает на такую разметку месячного листа:

| Что | Где | Настройка |
|---|---|---|
| Строка с датами | строка 2 | `ROW_HEADER` |
| Первая строка с артикулом | строка 3 | `ROW_FIRST` |
| Артикул продавца | столбец G | `COL_ARTICLE` |
| Наименование | столбец H | `COL_NAME` |

Заголовок столбца содержит дату и площадку: `31.08.2026` и `оз` или `вб`. Штук в коробке берётся из наименования: `…4шт` → 4, `…2 шт` → 2, иначе 1.

### Настройки в `CFG`

| Параметр | Смысл |
|---|---|
| `MODE` | `add` — прибавлять к тому, что в ячейке, `replace` — перезаписывать столбец |
| `SIGN` | знак записи, `1` — отгрузка положительная |
| `CLEAR_ACT` | очищать лист «Отгрузка» после разноски |
| `WARN_MISMATCH` | сверять выбранную площадку с текстом файла. `false`, если акты ВБ приходят с шапкой Ozon |
| `PLATFORM_ORDER` | порядок создаваемых столбцов пары |
| `FIXES` | замены при нормализации артикула |

### Сопоставление артикулов

Порядок поиска строки: точное совпадение нормализованного артикула → лист «Синонимы» (столбец А — как в акте, столбец B — как в таблице) → снятие суффикса `-Nшт`. Не найденные артикулы показываются в панели до разноски и пишутся в лог — их количества не разносятся.

### Известные грабли

- **Объединённые ячейки.** `clear()` их не снимает, поэтому лист «Отгрузка» пересоздаётся целиком. На месячном листе строка 1 обычно объединена поперёк дат — при создании новых столбцов формат копируется со строки 2 и ниже.
- **Часовые пояса.** Дата форматируется вручную, без `Utilities.formatDate`: она берёт пояс таблицы, а объект даты создан в поясе проекта, и на разных поясах терялся день.
- **Не тот файл.** Общий Excel из приложения содержит штуки, скрипт их домножит. Такой файл распознаётся и отклоняется с подсказкой.
